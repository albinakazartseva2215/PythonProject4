# PythonProject4

## Описание

Проект PythonProject4 _ это проект для использования классов и объектов 
на основе популярной темы e-commerce, подготовка материала для создания интернет-магазина. 
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота. 

## Установка
- [клонируйте репозиторий](https://github.com/albinakazartseva2215/PythonProject4.git)

- запустите файлы для обработки данных 
```
python utils.py
python main.py

```

## Использование
1. Перейдите на страницу в GitHub.
2. Создайте новую учетную запись или войдите в существующий.
3. Перенести проект в локальный репозиторий.
4. Откройте модули utils.py, main.py, 
   и внесите свои данные для обработки данных.
